# SPRINT 2: FRONT-END DESIGN & WEB DEVELOPMENT

Este projeto foi desenvolvido estritamente para fins acadêmicos, atendendo às especificações e exigências estabelecidas no curso de Engenharia de Software da FIAP. 

O objetivo principal é a apresentação conceitual de um aplicativo por meio de uma aplicação web. O foco do desenvolvimento está na interface e na experiência visual, utilizando conceitos básicos de estruturação e estilização para simular a navegação da plataforma, sem a implementação de funcionalidades de back-end ou banco de dados reais.

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das páginas e dos elementos visuais da aplicação.
* **CSS3:** Estilização, layout e responsividade para a simulação do design do aplicativo.
* **JavaScript:** Implementação de interações básicas e comportamentos visuais na interface.

## Características do Projeto

* **Foco Visual:** Desenvolvimento focado na fidelidade do design e na simulação da interface do usuário (UI).
* **Fins Acadêmicos:** Protótipo construído para validação de conceitos teóricos de Front-End.
* **Sem Funcionalidade Real:** Os dados exibidos são estáticos e os botões servem para demonstrar o fluxo de navegação planejado para o aplicativo.
